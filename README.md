# 🍻 Geiler Abend ist geil

Stündlicher Getränkeplan für einen Abend: jede Stunde braucht mindestens einen (alkoholischen) Drink.

- Drinks aus der Karte in eine Stunde **ziehen** (oder antippen → Stunde antippen)
- **Vorschläge** pro Stunde, passend zur Phase (Warm-up / Hauptteil / Endspurt) und zum Vibe
- **📌 Feste Drinks** bleiben beim „🎲 Neu würfeln“ erhalten
- **✨ Lücken füllen** belegt alle leeren Stunden automatisch
- Eigene Drinks anlegen, Plan per **🔗 Link teilen**, Speicherung im Browser

Reines HTML/CSS/JS, kein Build. Lokal: `index.html` öffnen. Online: GitHub Pages.

18+ · Kenn dein Limit · 💧 Wasser zwischendurch · 🚕 Danach nicht ans Steuer
